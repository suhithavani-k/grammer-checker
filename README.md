# ✍️ AI Grammar Checker

An AI-powered Grammar Checker built using **Python, Streamlit, and Groq**.  
This application helps users correct grammar mistakes, improve their writing, create professional rewrites, and understand grammar rules.

## 🚀 Features

- ✅ Grammar Correction
- ✨ Improved Writing
- 💼 Professional Rewrite
- 📝 Grammar Mistake Detection
- 💡 Clear Grammar Explanations
- 📚 Grammar Rules
- ⚡ AI-powered responses using Groq

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- LLM / Generative AI
